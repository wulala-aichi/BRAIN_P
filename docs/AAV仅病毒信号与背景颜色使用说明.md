# AAV 仅病毒信号与可选背景（3.13.0）

> 已按用户明确要求在3.13.1修正默认效果：保留整脑解剖，只去脑外黑矩形。下文为旧版“仅信号”可选模式说明，不再是默认推荐效果。请见《AAV整脑解剖与脑外透明使用说明.md》。

保存未完成的项目后刷新软件，进入“研究工作台 → Allen AAV 投射”。

“切面背景”选择 **仅病毒阳性信号（隐藏整脑解剖）**：隐藏 NIfTI 灰度矩形、全脑填色、脑区轮廓、自动脑区名称、十字线及2.5D解剖衬底，仅绘制当前阈值/平滑下的投射图层。片层坐标、比例尺与信号图例保留。3.13.1新建AAV图层默认整脑Allen灰度解剖，不再默认仅信号；旧项目仍保留其明确的背景选择，可手动切换。

在下方“画布背景颜色”选择：

- 透明：未绘制信号的位置保留透明，可导出PNG/SVG/TIFF。PDF查看器通常将透明页面显示为白色。
- 白色 / 黑色：使用对应纯色画布。
- 自定义颜色：用颜色选择器，或输入 `#RRGGBB`（例如 `#17324d`）。

画布与主面板的“透明 / 背景色”是同一份设置，随完整项目保存；深色画布自动使用浅色文字和比例尺。已加入图版的面板是快照，后续改颜色不会自动修改旧快照。

去背景和改颜色不改变原始投射值、mask、阈值、平滑参数或匹配数量。已加载的完整项目可离线去背景、改颜色，旧采样项目不会因此被强制升级数据渲染；如果其中已保存NIfTI背景，也可离线切回。换片层、实验或数据阈值仍需要本机服务。其他手动标注/研究数据不删除，可在各自模块独立关闭。

“阳性信号”指当前显示阈值下的投射像素，不是重新做病毒感染细胞分割，也不会自动去掉低于噪声生物学判定以外的有效信号；可用阈值控制弱信号显示。
