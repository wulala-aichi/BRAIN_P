# 手动标注与局部放大

入口：打开 `dist/index.html` → 右上角“图版编辑器” → 左侧“手动标注与局部放大”。先加入来源面板。

## 添加与编辑标注

- 选择“文字”，在来源图内点击添加。左侧可改文字、颜色、字号（pt）和线宽（pt）。支持最多四行文字。
- 选择“脑区名称 + 引导线”，直接点击脑区填色区域。自动读取该快照的脑区缩写或英文全名；随后可修改文字。没有脑区路径的统计图或 3D 位图不能自动识别脑区。
- 选择“箭头”“直线”或“框选区域”，在来源图内按住鼠标拖动。框选/线段至少 1 mm（图版显示尺寸），避免误点生成不可见标注。
- 完成一次绘制后自动回到“选择 / 移动”。拖动文字或图形移动；选中后拖动橙色端点调整锚点、线段或框角。脑区标签拖动文字时，脑区锚点保持不动。
- 来源坐标以快照宽/高的百分比保存，可在左侧精确调整。文字使用起点；脑区标签的起点是脑区锚点，终点是文字位置。
- 从“标注 / 插图列表”可选中被其他内容遮挡的标注。“删除选中标注”或非输入状态下按 Delete 删除，撤销/重做可恢复。Esc 取消正在绘制的草稿。

标注与来源面板绑定；面板移动、缩放、改变色条占用空间时，标注锚点跟随。手工标注字号和线宽采用图版物理单位，不随脑片缩小而缩小。复制面板时复制其标注；删除面板时连同该面板的标注和放大插图移除，可整体撤销。

## 局部放大插图

1. 选择“局部放大插图”，在来源图中拖出需要放大的矩形区域。
2. 插图直接裁取该面板的原始 SVG 内容。2D 脑区轮廓保持矢量；3D 或影像中的位图仍是原位图，放大不增加分辨率或补造细节。
3. 拖动插图调整位置，拖动右下角调整大小；也可精确输入插图 X/Y/宽/高（mm）。图像等比例放入插图框，不拉伸解剖结构。
4. 左侧起点/终点百分比控制来源裁取范围。可单独开关来源框、连接线和适用的真实比例尺。插图位置独立于来源面板，来源框和连接线跟随来源几何。
5. 修改来源面板的定量配色时，插图从同一来源重新生成，填色同步。原始数值和裁取范围不变。

放大插图默认包含同一来源面板的手动标注与植入物，可单独关闭。注射位点、光纤和 Neuropixels 的专用工具见 `注射光纤Neuropixels标注使用说明.md`。

比例尺仅对新捕获的、带空间校准信息的正视“当前活动切面”提供，按原始切面的变换和实际裁取比例推导。斜视薄片、3D 位图、统计图、整页快照或缺少校准信息的旧快照不显示组织物理比例尺；需要时返回主界面以正视单片重新捕获。所有坐标属于当前 Allen CCF 图谱，并非 bregma。

## 保存与导出

标注、裁取范围、插图位置、样式和来源面板编号随完整项目保存，并随浏览器图版草稿暂存。SVG/PNG 导出包含这些内容，不包含橙色选择框和调整手柄。SVG 的二维放大内容仍为路径和文本。

编辑器会提示文字标注相互重叠、遮挡面板标题或超出画布。箭头/框选覆盖脑图常是表达意图，不会被自动移动；导出前应检查手动文字是否遮挡需要展示的解剖结构。
