# PDF / TIFF 导出

版本 3.5.0，完全离线。更新后刷新 `dist/index.html`。

## 三个入口

- 主界面左侧“画布与导出”：PDF / TIFF 与当前二维单片、网格、三视图或 3D 一致。先设置导出宽度、背景与 DPI。
- “图版编辑器 → 导出图版”：画布大小采用图版毫米尺寸；保留面板、色条、手动标注和局部放大，不包含编辑框。
- “研究工作台 → 条件矩阵”：当前页 PDF / TIFF，全部页多页 PDF；批量格式也可选择 PDF 或 TIFF，ZIP 同时保留数值、数据来源、条件配方和完整项目。

## PDF 的矢量与位图边界

- 二维解剖轮廓、线条、几何标注、色条和普通文字保留矢量；连续色条以 512 条矢量色段近似，数值范围、反转与端点不变。
- 带描边/光晕的文字和阴影等效果按所选 DPI 嵌入局部位图，以避免转换器的描边缩放与字体基线差异；不会将整张二维脑图截图。
- 3D 场景、已导入影像和它们的放大区域仍是原有位图，不能通过 PDF 导出恢复更高的原始分辨率。图版中已捕获的 3D 面板不因提高导出 DPI 自动重渲染；需要更高细节时重新捕获面板。
- 普通中文及非基本拉丁字符使用随软件内嵌的 Noto Sans SC 正常/粗体，基本拉丁使用 PDF 标准 Helvetica / Times 字体。与界面字体可能略有字形差异；版面和手工换行不改变。字体没有的字符会明确报错，可改用 SVG / TIFF。
- 页面尺寸为真实毫米，不受显示器缩放影响。透明背景不额外绘制白色矩形；PDF 阅读器通常仍用白色纸张显示透明区域。

## TIFF

- 支持 150 / 300 / 600 dpi，X/YResolution 与英寸单位标签写入文件；像素数按“毫米 ÷ 25.4 × DPI”四舍五入。
- 透明背景输出 8-bit RGBA，未关联 alpha（ExtraSamples=2）；不透明背景先合成底色，再输出 8-bit RGB。
- 使用标准未压缩 TIFF，文件较大。它是结果图，不是 16-bit 定量体素或 NIfTI 数据；原始定量数值请用 CSV / 项目导出。
- 浏览器位图导出上限为一亿像素，超出时请降低 DPI 或缩小画布。矢量 PDF 不受整页位图像素上限限制。

## 建议检查

用独立 PDF 阅读器检查中文、色条与裁切；在图像软件中读取 TIFF 的分辨率与透明通道。投稿要求纯矢量标签时，使用 SVG 并在矢量编辑器完成最终排版。矩阵数据或配置改变后必须重新生成，才能导出与新配置一致的结果。
