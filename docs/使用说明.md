# Mouse Atlas Studio 使用说明

双击 `dist/index.html`，使用 Chrome、Edge 或 Tabbit 打开。日常使用不需要 R、安装依赖或启动服务器。

3.20 界面按“切片 → 数据 → 样式 → 导出”四步组织图谱设置。左上“使用指南”可按任务进入相应工作区；搜索框可以查找全部图谱设置（如“标签”“色条”“DPI”）。顶部的“研究数据”“MRI / 统计”“MRI 3D / 高级”和“图版排版”是独立工作区。原有专业参数都保留在可展开的设置组内，详见 `新版界面上手指南.md`。本地 MERFISH / AAV 大型数据仍可能需要启动对应的本地服务。

顶部新增 **MRI / 统计 NIfTI**：导入任意已配准模板、统计图和可选 mask，在独立 RAS 世界坐标中调节数值 / p 阈值、最小簇体素数 / mm³，浏览三视图或自定义多片，导出图像、簇表与二值掩膜。先载入模板再点“生成模拟 Z 统计图”即可验证，详见 `NIfTI模板与统计叠加使用说明.md`。不自动配准；簇大小过滤不等于 FWE/FDR 校正。

新版“研究工作台”入口在右上角，提供多动物数据与QC、点定位/ROI定量、组间比较、已配准图像、连接网络、ROI/轨迹、批量导出与精细标签接口。完整流程和精度边界见同目录 `研究工作台使用说明.md`。

研究工作台中的“条件矩阵”可把组别、时间点、指标和片层组合成多页比较图，分别显示组均值、B−A 或 Hedges g，按指标统一色阶、明确缺失单元，并加入图版或批量导出。详见 `多条件比较矩阵使用说明.md`。

“研究工作台 → 连接网络”顶部新增“功能连接球柱图 · 3D”。导入连接方阵/边表，可用 Allen 左右节点或自定义 CCF 坐标，调节正负连接、阈值、球/柱尺寸、标签和透明脑壳；保存项目并衔接图版及 PNG/PDF/TIFF 导出。先点击“载入模拟功能连接示例”可试用，详见 `功能连接球柱图使用说明.md`。

右上角“图版编辑器”可混排二维切面、完整网格、3D 快照和动物统计图，按毫米调整画布与面板，编辑标题/编号并导出 SVG/PNG/PDF/TIFF。图版使用 IndexedDB 自动暂存，并包含在完整项目中；详见 `图版编辑器使用说明.md`。

图版左侧“手动标注与局部放大”的绘制工具还提供注射位点、光纤和 Neuropixels：点击添加位点，从入口向尖端拖出光纤/电极，调节样式、标签、光锥或多柄触点示意，并随图版与局部放大导出。详见 `注射光纤Neuropixels标注使用说明.md`；当前按用户选择仅实现图版标注。

左侧“色条编辑器”支持方向、位置、毫米长度、刻度/数字格式、标题/单位覆盖以及同步脑图的反转和分级；图版也支持独立与经校验的共用色条，新 3D 快照会按原配方重渲染。详见 `色条编辑器使用说明.md`。图版中的“手动标注与局部放大”可添加文字、脑区引导标签、箭头、框选和保留原始几何的放大插图，详见同名使用说明。主图、图版与条件矩阵均已接入 PDF/TIFF 导出，矢量/位图边界、字体和 DPI 见 `PDF_TIFF导出使用说明.md`。

1. 在左侧“切面方向”选择冠状面、矢状面或水平面。
2. 选择“单片”“网格”“三视图”或“3D 脑区”。网格模式可自定义行数和列数（各 1–8，默认 2×4），总片数自动等于行×列。修改行数或列数后自动均匀选片：冠状面 AP 2.0–10.4 mm，矢状面 ML −4.0–4.0 mm，水平面 DV 1.0–6.6 mm；包含首尾，吸附至现有 0.1 mm 片层，只有一个面板时取区间中点。先点击一个面板或左侧带编号的坐标按钮，再用滑块、前后按钮或坐标输入框单独调节；“均匀选片”可恢复默认分布。打开已有项目会保留其中的手工片层，不自动重排。行列、每个面板的片层与当前选中面板均随项目保存，SVG/PNG 也按当前网格导出。列数较多时建议增大导出宽度以保持标签可读。
3. 在“着色图层”选择 Allen 解剖结构或现有的五个网络图层。解剖图可切换 Allen 原色、分组色或灰度。
4. 开启“脑区边线”或“外轮廓”，分别调节粗细。关闭开关即可完全隐藏对应线条。
5. 开启“透明背景”可导出透明图片；棋盘格仅用于预览，不会被导出。
6. 设置导出宽度和位图分辨率，选择 SVG、PNG、PDF 或 TIFF，浏览器保存到下载目录。SVG 保留二维矢量路径与文字；PDF 保留轮廓与普通文字，描边文字、阴影、3D/影像保持位图；PNG/TIFF 支持 150、300、600 dpi。详见 `PDF_TIFF导出使用说明.md`。

上方文件夹按钮打开项目（也兼容旧设置），保存按钮保存完整项目，回转箭头恢复默认。鼠标停留在脑区上，可在预览下方查看脑区、半球、数值和统计量。

浏览范围共 326 个片层：132 个冠状面、114 个矢状面、80 个水平面。层间距为 0.1 mm，各切面的轮廓来自原始 10 μm 注释。AP/DV 为 CCF 体积坐标，ML 为 NIfTI 左右坐标，未换算为 bregma。

HTML 已内嵌全部数据，可以单独复制到其他电脑使用。

## 分区名称与自定义伪彩

- 在“画布与导出”中开启“分区名称标签”，可选择 Allen 缩写或英文全称，并调整字号和密度。图中标签会自动避让；完整名称也显示在分区列表和鼠标提示中。
- 在“分区赋值 / 伪彩”中选择脑区结构、Allen 大分组或层级节点，查找分区并输入数值。输入后会自动切换到自定义伪彩。
- 也可以点击“下载模板”，在 CSV 的 `value` 列填写数值，再点击“导入 CSV”。脑区模板使用 `region,value`，分组模板使用 `family,value`；导入按缩写精确对应，也支持不区分大小写的名称匹配。
- 赋值优先级为：脑区结构 → 最近的层级节点/父区 → Allen 大分组；在同一层级，单侧值优先于双侧默认值。空值继承，无任何可继承值时使用未赋值颜色。数值可为零或负数。
- 伪彩支持 Viridis、青绿、蓝白红和 Inferno。可使用自动色阶，或关闭自动后输入下限和上限。当前色阶和数值标题会一并导出。
- “导出赋值”保存当前赋值层级中所有半球的显式赋值和 p/q/n，不把继承结果复制成独立赋值。当前选择的赋值半球影响手动编辑和模板，但不限制数值导出。

## 专业功能 2.0

### 1. 左右半球

“显示半球”选择双侧/左侧/右侧；“赋值半球”选择双侧默认 B、左侧覆盖 L 或右侧覆盖 R。半球按原始 NIfTI RAS 仿射定义：ML<0 为左侧，ML>0 为右侧，中线位于原始切片的 x=570 像素边界。显示使用矢量裁切，不改变原始轮廓，也不镜像生成解剖。

CSV 可增加 `hemisphere` 列，支持 B/L/R 和 both/left/right。未提供该列时，使用界面当前的“赋值半球”（默认 B）。没有半球列的旧 CSV 仍可使用。内置网络图层沿用原有脑区覆盖值，并不自动推算左右差异。

### 2. Allen 层级树

支持搜索数字 ID、缩写和英文名，勾选节点会选中其已渲染后代；可高亮或仅显示选区。点击节点缩写进入该层级赋值。层级节点支持 `structure_id,value` CSV。

内置 1327 个官方层级节点，但几何仍是 357 个聚合结构。灰色细分节点没有独立轮廓，不能赋值；尤其不能把树中列出的皮层层次视为已提供精细层次图像。父区数值只向下继承，不执行计数/密度/均值或统计量的向上汇总。

### 3. 统计阈值与色阶

CSV 可使用 `region,hemisphere,value,p,q,n`。`p`/`q` 必须介于 0 和 1，`n` 为正整数；缺失可留空。色彩表示 `value`，p/q 用于筛选。支持 `|value| ≥ 阈值`、`p ≤ 阈值` 或 `q ≤ 阈值`，以及效应量/t/z 类型和单位说明。

软件只显示导入的统计结果，不执行显著性检验或 FDR 校正。缺失所需 p/q 的区域与未通过阈值的区域显示为 Filtered 浅色，未赋值仍为 NA 灰色。手动改动数值会移除该赋值对应的旧 p/q/n，以免继续使用不匹配的统计量。

“以零为中心的对称色阶”将范围设为 [-M,M] 并切换蓝白红。自动范围根据当前显示半球在全图谱中的已赋值数据计算，不随显著性阈值变化；可关闭自动后锁定跨图比较范围。

### 4. 三视图联动

点击“三视图”，显示冠状、矢状和水平面。修改共享 AP/ML/DV 输入或点击脑片，三个切面同步更新；滑块和播放控制当前“切面方向”的坐标。十字光标可关闭，三视图可整体导出。

坐标吸附至 0.1 mm 浏览片层；它不表示 10 μm 连续定位精度。AP/DV 是距 CCF 体积前/背缘的距离，ML 是原始 NIfTI 的 RAS x，不是 bregma。图中 L/R/A/P/D/V 分别表示左/右/前/后/背/腹。

### 5. 完整项目

在“项目与来源”填写项目名、来源/方法和备注。点击上方保存按钮，导出 `.mouseatlas.json`，包含数值、p/q/n、原始导入 CSV、导入记录、色阶、阈值、半球、选区、排版、共享坐标和图谱版本指纹。

文件夹按钮恢复项目；图谱版本不匹配时会拒绝载入，不覆盖当前项目。项目保存全部用户数据，但不重复嵌入基础图谱；分享时同时提供本 HTML 与项目 JSON。恢复默认会清空当前界面数据和导入记录，不删除磁盘上的项目文件。

## 片层间距：排版与实际取片

在“网格”模式的行列设置下，分别提供两类控制：

- **排版图间距**：横向、纵向独立调节，默认24版面单位（保持旧版排版）。滑块0–100，右侧mm数值按当前导出宽度折算；这是面板额外留白，脑片外缘间的实际空白还取决于脑片大小和安全边距。增加横向间距会缩小面板，纵向间距会改变整张图的高度，不改变任何取片坐标。“恢复默认图间距”只恢复这两个参数。
- **按实际间隔选片**：填写当前AP/ML/DV方向的“起始坐标”和“取片间隔”（单位mm），检查预览后点击“按间隔应用”。片数等于行×列，坐标依次为起点＋序号×间隔；例如2×4、AP起点2、间隔0.5，得到2.0、2.5、3.0、3.5、4.0、4.5、5.0、5.5 mm。

实际选片吸附到现有约0.1mm浏览片层，不进行插值；界面显示吸附后的起止、真实相邻间隔和最大偏差。半步等距时固定选择较低坐标。低于浏览分辨率、越界或导致重复片层时禁用应用，并保留原片层。只编辑输入框不会自动改变脑图。

修改行列或切面方向仍按原规则恢复默认范围均分；“均匀选片”也保留，冠状面默认AP 2.0–10.4 mm。逐面板手动调整仍可用。两类参数、已选片层均随项目及浏览器本地设置保存，旧项目不含新参数时使用默认图间距24，保留其已保存的手动坐标。预览、SVG/PNG与批量导出共用排版，SVG元数据记录版面间距和实际片层坐标。单片、三视图及3D模式不使用网格间距设置。

## 2D 立体薄片

二维预览和SVG/PNG导出不显示切面周围的L/R、A/P、D/V方位字母；片层坐标标题、脑区名称和比例尺按原设置保留，三维坐标辅助选项不变。

左侧“2D 立体薄片”中打开“开启立体效果”。默认关闭以保持既有项目外观；旧项目没有该设置时也保持平面显示。

- 网格和三视图：保持正视，增加统一的薄侧边和柔和投影；用“显示厚度”0–24、“阴影强度”0–45%调节。厚度会随小面板适当缩小，不是实际组织切片厚度。
- 单片：增加上下倾角和左右转角（各 −55° 至 55°），可点击“正视”或“斜视”。开启“拖动旋转模式”后，在脑片上拖动即可调整；绘制自定义ROI时自动让位于绘图操作。
- Allen 解剖色、伪彩和网络图的正面均不叠加光照或渐变，不把数值映射成高度；厚度不用于任何面积、体积或细胞密度计算。
- 旋转采用可逆的正交投影，脑区、实验点、连线和ROI一起变换，文字标签保持水平并重新避让。倾斜会改变屏幕上的长度，所以倾斜时隐藏普通比例尺；点击“正视”恢复。
- SVG、PNG、批量导出均包含当前效果和“仅为显示厚度”的说明；SVG保留原始脑区路径及独立装饰图层。设置随项目文件和浏览器本地设置保存。关闭效果可恢复原始2D图形。

该模式是示意性的2.5D薄片，不是相邻真实片层构成的组织体积，也不显示真实厚度方向上的脑区变化。真实三维表面仍使用单独的“3D 脑区”模式。

## 3D 脑区

在左上显示模式中点击“3D 脑区”。三维表面从原始 10 μm 注释体积抽样为 100 μm 后提取，并使用保留中线约束的 Taubin 平滑改善阶梯边缘。平滑只用于显示，不改变原始二维轮廓、脑区统计或导入数值，也不应用于体积测量。

“表面平滑强度”可在 0–200 之间调节：0 关闭平滑、100 标准（默认，保持旧版外观）、200 增强，也可点击三个快捷按钮。滑块在原始、标准 Taubin 与双倍循环的增强网格之间连续插值；不是提高原始图谱分辨率。脑区和背景脑壳同步调整，中线仍固定。较高强度会弱化细小结构，建议从 100 开始比较。设置随完整项目及浏览器本地设置保存，旧项目未包含该项时默认 100；PNG 按当前强度导出，并在图中注明强度。

- 拖动旋转，滚轮缩放，Shift 或右键拖动平移；“重置视角”和背侧/前侧/右侧按钮提供标准视角。
- “坐标辅助显示”可选关闭、坐标轴、切面位置或两者，默认关闭。选择切面后可分别勾选 AP 冠状、ML 矢状、DV 水平面。坐标轴 AP+ 指向后方、ML+ 指向右方、DV+ 指向腹侧；坐标原点不是 bregma。
- “显示半球”“填充不透明度”、层级选区及“仅显示选中分区及后代”同样作用于三维。背景脑壳的透明度独立可调。
- Allen 配色受三维光照影响。伪彩和网络模式仅显示有值且通过筛选的脑区网格；外壳只作空间参照，不能解读为未赋值脑区的统计值。
- 点击表面查询名称、左右侧和数值，并选中对应脑区、更新共享 CCF 坐标；“查看选点三视图”可转入二维联动定位。选择的是可见表面交点，不是内部体素。
- 3D 支持 PNG、PDF 和 TIFF 导出，三维场景始终为位图；SVG 只适用于二维图形。相机、坐标辅助、切面选择等设置随完整项目保存。

当前三维包含 712 个网格（含全脑外壳），覆盖 356/357 个聚合结构；极小的 `c` 区在 100 μm 抽样中未保留。二维图谱仍保留全部 357 个结构。HTML 已内嵌三维数据和平滑参考网格，首次进入 3D 需要解压并创建网格；浏览器需支持 WebGL。
