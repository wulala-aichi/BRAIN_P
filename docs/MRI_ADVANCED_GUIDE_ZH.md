# MRI 高级结果展示（3.19）

## 3.19.2 · 横纵图间距独立编辑（支持负值）

高级窗口画图区上方提供 **横向间距 mm / 纵向间距 mm** 两个数值框（−30～30mm），以及 **重置间距**。正值留白，0表示面板接触，负值允许有意压叠，例如横向−5mm、纵向−8mm。修改后自动进入成图预览，重置仍为各3mm。它们调整的是图版排版，不是取片坐标的步长，也不会改变真实统计信号的叠加。

“当前交互视图”的多平面/Mosaic同样使用独立面板排版，不再绕过间距设置。各面板有独立裁切边界；非负间距避免跨图重叠，负间距则允许整块面板重叠，后绘制的图可能遮挡下层图像或标注。侧边colorbar不会缩放已输入的毫米间距。单张图没有相邻面板，间距只在多图时体现。若负值过大导致排版反向超出画布，会提示减小负值或增大画布。

多面板中的脑外区域始终透明，最终画布再统一填充所选背景色。因此即使最终导出白底或深色底，负间距时也不会用单张图的背景矩形擦掉下层脑片；只有实际脑组织和已开启的标注参与遮挡。

原 **MRI / NIfTI 统计展示 → 切面与图版** 也有横向/纵向图间距，默认各4mm。新设置会随完整项目和高级显示配方保存；旧配方中的统一间距会沿用到横纵两个方向。

## 3.19 · 多种组合出图

画图区上方 **出图组合** 下拉菜单提供：当前交互视图、三切面横排、三切面竖排、三切面＋3D四格、三切面＋3D横排、单切面＋3D、背侧/前侧/右侧3D三联图、自定义切片矩阵。

左侧 **成图 · 组合、坐标与文字** 可调面板间距、矩阵行列（各1–6）、切片方向和编号开关。矩阵默认均匀覆盖底图该轴10–90%的范围；取消自动范围后，可手动输入起止世界坐标mm。单格矩阵采用范围中点；倒序范围也可使用。间距过大时会提示增大画布或减少行列。

三切面采用当前游标位置；单切面＋3D可选择水平/冠状/矢状方向。除多角度3D预设外，组合中的3D采用当前相机。需要改变视角时点击 **交互调整**，调整后回到 **成图预览**。组合捕获完成会恢复原来的视图、相机和游标，不修改源影像、ROI或统计阈值。各面板共用图外色条，坐标、切面名称、编号仍可独立开关；PNG/SVG/PDF与预览一致。

## 3.18 · 直接成图、可选文字和独立色条

高级窗口默认显示 **成图预览**，可直接点击画图区上方的 **直接出图 PNG / SVG / PDF**。预览与导出使用同一SVG排版；需要旋转、定位、画ROI时点击 **交互调整**，完成后点击 **成图预览**。

左侧 **成图 · 坐标与文字开关** 可分别选择图题、各切面世界坐标、切面名称、来源说明、测量线/数值，调整标注字号和颜色。方向字母、十字线、方向立方体及比例尺仍在“视图与坐标”中独立控制。“关闭全部文字”会保留勾选设置并暂时隐藏所有成图文字；“纯脑图”还会关闭色条和定位标记。来源、原始坐标、统计阈值仍保存在图像元数据中，不因隐藏标注而删除。

左侧 **Colorbar · 标注与尺寸** 可调整横/竖、上/下/左/右位置、对齐、长度mm、厚度mm、字号pt、刻度数和数字格式；标题/单位、刻度数字、刻度线、边框均有独立开关。每个图层可单独设置色条标题、单位和正/负刻度。色条采用该图层实际LUT及显示阈值，不改变统计值；隐藏图层不会留下色条。多个色条自动换行/分区，预留图外空间。

原 **MRI / 统计 NIfTI** 窗口也支持图题、片层坐标、切面名称、坐标系说明和阈值/方法说明的独立显示开关，色条编辑器同样增加文字及边框开关。旧项目已显式保存的方向/十字线/比例尺设置仍会保留。

打开 `dist/index.html`，点击顶部 **MRI 高级展示**。原来的 **MRI / 统计 NIfTI** 仍负责统计阈值、簇过滤和模板显示平滑。

## 快速开始

1. 在 **MRI / 统计 NIfTI** 中载入模板与统计图，确认空间单位、缩放及配准，应用统计阈值和簇大小。
2. 点击统计窗口中的 **高级 2D / 3D 展示**，或返回主界面点击 **MRI 高级展示**，选择 **载入统计模块当前结果**。
3. 高级窗口左侧分为七组：数据/图层、视图/坐标、3D/相机、Mosaic/MIP/4D、ROI、表面/纤维、导出/场景。点击组标题展开。
4. 先选图层，再调整独立色阶、正负色带、透明度、显隐和色条。滚轮切片、左键定位/旋转；鼠标工具可切换平移、窗宽窗位、距离、角度、画笔、矩形、椭圆和橡皮。
5. 从 **可复现出图与场景** 导出 PNG、SVG、PDF，或加入现有图版编辑器。图宽和 DPI 决定输出像素；SVG/PDF 中脑影像是高分辨率位图，文字与比例尺单独绘制。

## 直接加载本地影像

高级窗口也可直接加载本地 NIfTI；第一个文件为底图，后续为叠加。导入叠加前须勾选 **确认所有叠加已配准到同一空间**。目前高级入口要求文件头声明 mm，并有有效 sform/qform；不会自动配准或猜测缩放。

模板的空间尺度不能仅凭文件名自动更改。若模板提供方明确说明有缩放，请在原统计模块确认并设置空间缩放，再传入高级窗口；所有图层必须采用一致空间。不要把RAS世界坐标直接当作bregma坐标。

## 常用功能

| 任务 | 操作 |
| --- | --- |
| 三视图与3D联动 | 视图选择“三视图 + 3D”，输入 X/Y/Z mm 后定位 |
| 前/后/左/右/背/腹侧 | 在3D相机组点击对应按钮；也可输入方位角和仰角 |
| 玻璃脑/实体脑 | 使用预设，再调底图透明度、光照、轮廓和梯度透明度 |
| 裁切 | 单平面深度/方位/仰角；或每行输入 `depth,azimuth,elevation`，最多六个平面 |
| 均匀多切片 | 设置行列、方向和毫米起止坐标，点击“生成均匀图版” |
| MIP | 选择图层、原网格投影轴和 max/abs/min/mean；不是任意旋转的3D MIP |
| 4D | 选4D图层，调整从0起的帧号、播放帧率及游标曲线 |
| ROI | 选绘制工具和标签/笔宽，绘制后可撤销、清空、载入或导出 NIfTI |
| ROI描述统计 | 按所选影像原生网格、当前4D帧、世界坐标最近邻ROI计算；标签>0取并集，包含有效零值；空ROI返回空统计，不伪造均值 |
| 标签图谱 | 标签影像作为叠加导入，再载入 R/G/B/A/I/labels JSON 色表 |
| 表面/纤维 | 导入已配准的本地几何；OBJ与TCK已做交互测试，其余列出的格式由引擎支持，需用实际文件验证 |
| 批量旋转 | 设置帧数，导出逐帧PNG ZIP；完成后恢复相机，可中途停止 |
| 完整场景 | “保存完整高级场景”包含影像、ROI、相机和图层；“保存完整软件项目”还包含原统计模块及现有图版 |

二维比例尺按当前切片视野自动选择毫米长度；3D透视视图不显示不可靠的二维比例尺。定位字母、方向立方体、十字线均可关闭。

## 统计值与显示阈值

高级窗口的色阶是**显示控制**，不会进行新的显著性检验、FDR/FWE校正或簇推断。需要 p、自由度、簇体素数或体积过滤时，先在原统计模块应用，再传入高级窗口。

传入的统计图只保留通过过滤的体素，剔除体素为透明零值；传入的解剖图可带已设置的显示平滑。概率图用于3D显示时转换为 −log10(p/q)，并在来源元数据中记录；原统计数据及分析结果不变。p=0 仅为显示作有限值截断，不代表重新估计概率。

## 保存与复现

完整项目/高级场景较大，建议保存到本地文件，不依赖浏览器缓存。无影像配方只保存视图参数，需自行重新加载一致的影像。所有影像处理在本机浏览器进行，不上传数据；首次打开高级窗口需要 WebGL2。

示例目录 `examples/mri_advanced/` 包含明确标记的模拟4D、OBJ、TCK、色表及完整测试项目。模拟统计结果仅验证软件，不是科研发现。

## 与 MRIcroGL 的边界

这是 MRIcroGL 风格的浏览器工作流，不是桌面 MRIcroGL 的逐像素移植。浏览器不执行原生 Python；可导出基础 `gl` 视图脚本及 NIfTI，供另行在 MRIcroGL 中运行。自定义浏览器色带、ROI和 MatCap不保证通过该脚本完全复现。

默认使用已验证的标准体渲染。当前引擎的 ROI 与 MatCap 光照组合有彩色噪点兼容性问题，因此载入/创建 ROI 后会明确切换为标准体渲染，保留ROI和数据；无ROI场景可使用MatCap。自定义MatCap图像保存在高级场景中。

桌面专属着色器逐项兼容、任意旋转MIP、DICOM转换、自动配准/分割及任意Python执行不在本次浏览器实现中。当前统计、ROI和坐标信息需结合研究流程独立验证，不能把显示效果当成统计证据。
