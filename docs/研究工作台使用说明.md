# Mouse Atlas Studio 研究工作台

打开 `dist/index.html`，点击右上角“研究工作台”。保留本地离线使用，不上传实验数据。数据页→样本筛选→点与定量→组间比较是主流程，其余模块按需使用。

## 1. 多动物长表与QC

必需列为 `sample_id,region,value`，推荐同时提供 `group,timepoint,hemisphere,metric,unit,sex,batch`。一个样本编号应对应一个独立实验动物；重复测量使用同一个编号和不同时间点，不能通过改名伪装为独立动物。`examples/simulated_animals.csv` 和工作台“载入模拟长表示例”均为模拟数据。

1. 数据种类选择“多样本脑区数值长表”，选择CSV。
2. 检查列映射，可将自定义表头映射到规范字段。
3. 预览显示全部记录总数、错误/警告数及前100行，QC报告可下载全部问题。
4. 重复记录、未知脑区、空/非法数字、非法半球及同动物元数据冲突不会被静默覆盖。默认有错误时不允许提交；如明确勾选“仅导入通过检查的行”，才导入有效行。
5. “追加”会检查跨文件重复；“替换”只替换当前种类的数据。原始CSV、列映射、导入时间及SHA-256随研究项目保存。

空值不等于零，负值和数值0均为有效值。组别未提供时显示“未分组”。旧的 `region,value,p,q,n` 单图赋值入口仍保留在主界面左侧。

## 2. 筛选与脑图

在“样本与脑图”选择指标、组别、动物、时间点和半球，然后应用到脑图。均值按每只动物一条脑区记录计算；同一动物有多个时间点时必须先选定时间点，单位不同的同名指标拒绝合并。

B是双侧汇总，L/R是单侧口径。不同口径不自动互相推算，也不能把B、L、R再次相加。研究工作台原始数据不会因“应用到脑图”而丢失。

## 3. 点坐标与定量

点表建议：`sample_id,group,timepoint,point_id,ap,ml,dv,cell_type,intensity,positive`。

- 单位明确选择mm或μm，先确认坐标已注册到当前Allen CCF。
- AP/DV分别从CCF体积前缘/背缘计数；ML为NIfTI RAS左右坐标；不是bregma。可通过列映射指定x/y/z的轴含义，但不会自动推断配准或原点。
- 内置点归属来自原始注释的100μm规则抽样，而不是10μm定位。与六个邻体素标签不一致的点标记 `boundary=true`，建议在更高分辨率原始标签或图像中复核。
- 超出体积的点保留在导出中，但不参与脑区计数；位于未标注组织的点不被强制分配到最近脑区。
- 二维点只显示在当前片厚内；三维按当前筛选显示。为了交互性能，每个视图最多显示前50000个点，计数仍使用全部导入点。

“生成动物级ROI定量”输出细胞数、参考图谱密度、有阳性标签点的阳性比例和有效强度的均值。密度使用**原始10μm注释逐体素计数**的脑区体积，不使用平滑表面；这不是样本真实组织密度。要计算样本密度，须导入校准的样本标签/体积并说明配准及形变处理。

只有明确声明各样本具有完整全脑检测覆盖时才对无点脑区补0；否则缺测脑区不冒充零计数。父级脑区通过其不重叠聚合结构重新统计点与体积，不把子区密度、均值或p值相加。

## 4. 两组比较

支持独立动物的两组双侧Welch t检验，差值为B−A，输出nA/nB、均值、差值95%置信区间、Hedges g、t、自由度、p与BH校正q。BH范围仅为所选指标、时间点、半球和对比内具有有效p值的脑区；没有自动跨多个对比再次校正。

n<2或两组方差均为0时不伪造p值；样本不足和零方差状态保留在表中。点击脑区选择器查看每只动物的散点，横线表示组均值，底部文字为差值的置信区间。支持A/B/差值并排脑图，共用色阶。不能将细胞或切片当作独立动物；配对、重复测量、批次/性别等协变量模型请导出数据后在R/Python分析。

## 5. 图像与精细标签

标量图支持单文件NIfTI-1 `.nii/.nii.gz`，读取sform优先、qform次之，应用缩放参数并显示首个三维帧。需有明确毫米空间单位和可逆仿射，用户确认已与当前CCF对齐；可调强度范围、灰度/色带和不透明度。请用三视图配合边界检查配准质量；视野交叠检查不等于配准准确性评估。

PNG/JPEG切片按当前方向、位置和完整原始视野放置，仅适合已经对齐的切片，不自动旋转/缩放配准。NIfTI图像叠加目前用于二维，不是三维体渲染。

标量体积可填写动物编号、组别、时间点和单位后执行“汇总当前体积脑区信号”。输出 `mean_signal` 与 `registered_coverage_mm3`：所有有限体素（含0）参与、NaN/Inf忽略，按当前标签来源归属；注册空间覆盖体积不等于未形变的样本原始组织体积。多只动物可依次导入，动物级结果保存在研究数据中。

精细标签模块先导入 `code,region,name,color` CSV，再导入真实整数标签NIfTI，并确认CCF空间一致。点归属、参考体积和二维栅格标签叠加改用该文件；可将研究数值应用为细分标签伪彩。它不会为缺少几何的层级节点生成假轮廓，也不会替换基础357结构SVG/3D网格。其他物种/坐标空间需要独立适配，不直接套用此入口。

主脑图的基础名称标签及常规点击查询仍对应Allen底图；细分结构名称请查看导入结构表和点归属结果。双侧连接节点使用双侧标签的质心，常位于近中线；选择单侧显示时改用该侧质心。

浏览器限制为单个体积最多128M体素；更大数据请先在本地降采样或在外部工具处理。显示栅格最长边256像素，影响展示而不是体素定量。

## 6. 连接网络

导入 `source,target,weight` 或带脑区行/列表头的方阵。正连接红、负连接蓝，可调绝对权重阈值及最大显示边数；默认最多300边，完整输入保存在项目。无向矩阵必须对称，有向矩阵保留方向。二维只连接当前切面有区域锚点的脑区；三维使用100μm标签质心，有向边显示箭头。连线只是连接关系，不能解读为实测纤维束。矩阵预览最多前40个节点，点击首列节点可在主脑图选中。

## 7. ROI与轨迹

点击“在脑片绘制ROI”，在同一片层点击至少3点，再用左侧“完成ROI”。面积由标定坐标计算，点计数仅统计指定片厚内的点。可导出多边形、计数JSON和最后ROI的单层NIfTI二值掩膜；掩膜厚度来自片厚设置，是柱状ROI，不是完整组织分割。

删除已完成ROI：进入“研究工作台 → ROI/轨迹”，在“已完成的ROI”列表对应行点击“删除”并确认；“清空全部 ROI”只移除全部已完成ROI。删除后脑图、列表和派生面积/点计数会同步更新，并自动保存到当前浏览器；CSV、实验点、轨迹、统计、图像及其他设置均保留。尚未完成的多边形用左侧“取消绘制”移除，不受清空已完成ROI影响。之前另存的项目文件不会被修改，可通过重新打开旧项目恢复，或在删除后另存更新后的项目。

轨迹CSV为 `sample_id,group,track_id,order,ap,ml,dv`，报告折线长度及经过的脑区（内置定位100μm、沿路径0.05mm抽样）。SWC入口将父子段转换成轨迹；要求已配准且明确x=AP、y=ML、z=DV和单位，不会自动识别原始神经元空间。所有轨迹可在三维展示。

## 8. 批量、保存与接口

批量按动物或组均值生成当前指标/时间点/半球的二维SVG或当前DPI的PNG，统一使用对称色阶并恢复原脑图。ZIP包含图、动物长表、统计结果、方法清单、完整项目与带图谱指纹/共享范围的manifest。批量组图不混入未按组筛选的实验点和连接边。三维批量图暂不支持，单张3D PNG仍可正常导出。

主界面保存按钮或“导出完整项目/分析配方”包含研究数据、点、轨迹、连接、ROI、统计、原始CSV以及导入的体积文件。浏览器本地自动保存只保存体积描述，不重复写入大文件；刷新后需重新导入体积或打开包含资产的完整项目。精细标签缺失时不会改用内置标签重算其定量。

新研究项目格式为version 2，仍能读取原version 1项目。旧版HTML会拒绝打开version 2，避免其忽略研究字段后重新保存而丢失研究数据；分享时请使用当前配套HTML。

CLI示例（输出目录内已有同名结果会拒绝覆盖）：

```powershell
node tools/research_cli.mjs compare --input examples/simulated_animals.csv --out my_analysis --metric simulated_signal --group-a Control --group-b Treatment --timepoint day1 --hemisphere B
```

`examples/make_research_input.py` 和 `.R` 示范生成规范CSV；数据均为模拟值，不代表生物学结果。复杂注册/模型可在外部完成后，通过CSV、已配准NIfTI和项目JSON接回本软件。
