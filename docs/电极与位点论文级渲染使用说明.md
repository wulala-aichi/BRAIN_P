# 电极与位点论文级渲染（3.14.1）

先保存当前项目，再刷新本地软件页面：http://127.0.0.1:8765/ 。离线版也已更新到 `dist/index.html`。

## 3D坐标标注

1. 打开“研究工具”→“位点与电极”，保留或导入自己的入口、尖端和位点CCF坐标。
2. 点击“应用论文级预设”。它启用精细器件、淡灰透明脑壳、7 pt标签和0.6 pt引导线，并隐藏分区色块；不改坐标、直径、柄数或示意触点数。
3. 调整视角；按需选择标签位于左侧、右侧或自动排列。“前景”使器件完整可见，“深度”按实际遮挡显示。
4. 可直接导出PNG/PDF，或加入“科研图版编辑器”排成多面板。图版中缩放面板后，论文风格的3D标签保持指定物理字号。

电极改为薄片尖端与矩形触点，光纤分为外层、内芯与端面；注射位点为空心标记，避免遮挡解剖。经典风格仍可选，旧项目不会自动变换。

### 六向标准视角（3.14.1）

3D模式左侧有“背侧 / 腹侧”“前侧 / 后侧”“右侧 / 左侧”三组成对按钮。“右侧 / 左侧”按小鼠解剖侧定义。背腹视角已改为准确垂直观察，不再略带倾斜；所有按钮回到居中、相同观察距离，方便跨视角比较。“重置视角”恢复原来的斜视角。切换只影响相机，不改变实验坐标、脑区或赋值；需要固定结果时，从所需视角重新加入图版面板。

## 2D图版示意标注

1. 在主界面设置切面，打开“科研图版编辑器”，点击“当前活动切面”。
2. “手动标注与局部放大”中选择注射位点、光纤或Neuropixels；点击定位位点，从入口拖向尖端绘制器件。
3. 选中一个器件，点击“本面板论文风格”，统一该面板全部器件为7 pt文字、0.6 pt线宽、空心位点及较细器件。
4. “本面板标签避让”重新排列标签；仍可手动调整标签偏移。检查底部重叠/越界警告。

自动避让只移动标签；器件入口、尖端和注射中心保持不变。新加入的正视单片，其图版比例尺文字保持6 pt，标尺所代表的1 mm长度不变。

## 输出与科学含义

- 按期刊最终图宽设置画布，再导出SVG/PDF或600 dpi PNG/TIFF。2D器件、普通文字和3D引导标签可编辑；3D脑和器件主体为嵌入位图，不是全矢量网格。
- 透明背景和白色背景仍可切换。投稿白底图建议关闭图版的“透明背景”。旧的固定快照不会自动重绘，需从当前视图重新加入面板。
- 3D坐标使用软件中的Allen CCF坐标约定，不自动等同于Bregma手术坐标。2D手绘器件的尺寸是图版mm，不是脑内实测尺寸。
- 器件外观/触点是示意，不是厂商CAD、真实通道定位或组织学重建。位点直径不代表病毒扩散范围，光锥不代表实测光场。
- `outputs/implant_publication_v314_20261019` 中所有 `SIMULATED` 文件都是功能演示数据，不可当作实验结果；可打开示例完整项目继续修改。

本次使用现有HTML/SVG/Three.js渲染器完成本地开发和浏览器验证，未改动原始Allen、病毒或实验数据。具体投稿仍需按目标期刊核对尺寸和格式。
