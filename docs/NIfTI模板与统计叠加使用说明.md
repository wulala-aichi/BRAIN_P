# 本地 NIfTI 模板与统计结果展示（3.16.1）

刷新软件页面后，点击顶部 **MRI / 统计 NIfTI**。这是独立的 MRI 世界坐标查看器；不会把任意模板强行解释为 Allen CCF。

## 快速测试

1. 在“解剖模板”选择自行提供且有使用权限的NIfTI模板，或README中生成的合成phantom。
2. 默认保留文件头坐标（×1）。只有在模板来源明确规定空间被缩放时才调整倍率；不是自动配准，也不改写原文件。不可单凭文件名决定缩放。
3. 点击“生成模拟 Z 统计图”：软件在模板原始网格生成两个正/负 Gaussian 信号簇和一个小簇，并同步刚才选定的缩放。结果和导出图始终带 `SIMULATED` 标记。
4. 调节原始值阈值和最小簇体素数，检查预期簇的保留/排除。具体簇数和体积由你所选模板、网格及阈值决定。
5. 把阈值方式改成“由 voxel p 换算”，使用双尾 `p=0.001`，Z 阈值应约为 **3.29053**。

公开版示例由`node scripts/generate-example.mjs`生成。合成统计图为任意原始数值，不应作为真实Z统计推断；使用原始值阈值模式。导入自己的统计文件时需确认空间与模板一致。

## 真实统计图

支持3D及多体积 **NIfTI-1** `.nii` / `.nii.gz`，单帧最大3200万体素。支持常见整数与浮点类型、scl_slope / scl_inter、sform / qform。4D文件可选择目标帧；不支持NIfTI-2或hdr/img配对。缺失有效空间affine或单位时会要求先修复文件头。

- 同空间的模板与统计图可以有不同体素尺寸、矩阵大小；根据 affine 世界坐标采样。仅范围重叠不等于已经配准。
- 解剖图三线性插值，统计图和分析掩膜最近邻采样；阈值和聚簇始终在统计图的原始体素网格上计算，不在显示切面上计算。
- 根据 NIfTI intent 自动识别 t / Z / F / p / ln(p) / log10(p)；未注明时手动选择。不会按文件名猜统计语义。
- t 转 p 阈值须输入正确 df；F 须输入分子和分母自由度，使用上尾；t / Z 可选单尾或双尾。单尾时须明确正向或负向。
- p / q 图采用 `≤ alpha`；1−p 采用 `≥ 1−alpha`；−log10(p) 采用 `≥ −log10(alpha)`。标准 NIfTI intent 24 是 **log10(p)**，采用负值和 `≤ log10(alpha)`，不能当作 −log10(p)。
- p=0 是有效概率。如果文件将脑外填成 0，请启用忽略0并使用分析掩膜，或限制到模板正值范围。没有符号的 p/q 图不能恢复正负效应方向。
- q 与已校正 p 只展示外部分析提供的数值；校正标签不执行额外校正。

## 簇与脑外过滤

先统计阈值，再按 6 / 18 / 26 邻域计算 3D 连通簇，正、负值分开。最小簇体素数 k 和最小 mm³ 需同时满足；mm³ 使用统计图 affine 行列式，并随明确选择的空间缩放改变。`k` 与体积只是范围过滤，**不是 FWE / FDR 校正或簇水平显著性检验**。

默认仅在模板正值范围显示统计候选体素，可调模板灰度阈值；也可载入同空间的外部 mask（大于0为有效）。灰度模板正值范围不等价于经过人工核验的脑组织掩膜，严格分析请使用独立的标准脑掩膜。

## 切片与出图

支持联动的冠状 / 矢状 / 水平三视图、单片、自定义1–6行列。多片起止位置为对应轴的 RAS mm，均匀分布。鼠标点击联动世界坐标，单片/三视图滚轮切层；簇表点击定位峰值。采用 neurological convention（图左为解剖左），不是 bregma 坐标。

可调整解剖窗、统计透明度、21种色带、色阶、色条、十字线、方向字母、比例尺和透明/白/深色背景。更改统计/空间参数后旧结果会隐藏，需点击“应用阈值”；视觉参数变化不重新计算簇。

### 模板显示平滑

在 **3 · 切面与图版** 中勾选“模板三维高斯平滑（仅显示）”，用滑块或数字框设置 **σ=0–3体素**；可先试0.5–1。默认关闭；σ=0或“恢复原始模板显示”会精确恢复未平滑显示。

算法在模板原始体素网格执行三维可分离高斯卷积，采用原始模板有限灰度大于掩膜阈值的支持范围，对有效权重归一化，最后重新限制到该原始范围。不会把平滑灰度扩展到新的脑外像素。它是灰度显示平滑，不改变脑边界几何，不等于增加真实空间分辨率。

σ的单位为**体素**，不是mm；界面显示当前缩放空间的 X/Y/Z 轴向 FWHM（约 `2.35482 × σ × 各轴体素间距`）。非等距/斜切网格不应将它解释为世界空间中严格各向同性的核。演示模板选择×0.1时，σ=1约对应各轴0.1413mm FWHM；选择×1则约1.413mm。

只改变解剖背景显示副本，不处理统计图，不改变统计阈值、模板分析掩膜、簇表、体积或导出的二值统计掩膜，也不改写原始NIfTI字节。首次计算会显示进度，切层/换色使用缓存；改变强度后重新计算。PNG/SVG/PDF和图版使用当前显示结果，SVG元数据与完整项目保存平滑配方，项目回读时重算缓存；旧项目缺省为关闭。

可直接导入 `examples/nifti_stats/SIMULATED-NIfTI-template-smooth-v3161.mouseatlas.json` 试用σ=1的三视图演示。

- SVG / PNG（300或600 dpi）/ PDF。
- 簇表 CSV：k、mm³、原始峰值、峰坐标、质心坐标及阈值信息。
- 二值阈值掩膜 NIfTI：统计图原网格，保留已应用的空间缩放 affine；不修改原统计文件。
- 加入图版编辑器：固定快照，包含来源、阈值和空间元数据。
- 完整项目：嵌入原始本地文件字节及全部 MRI 设置，重新导入可恢复；仅刷新网页不会自动重新读取磁盘中的本地文件。项目可能较大。

SVG/PDF 的切面是嵌入的原始信息量位图，文字、色条和比例尺为矢量；提高导出 DPI 不增加模板的真实解剖分辨率。

## 方法依据

[NIfTI 官方 intent 定义](https://nifti.nimh.nih.gov/nifti-1/documentation/nifti1fields/nifti1fields_pages/group__NIFTI1__INTENT__CODES.html/document_view.html)；[NIfTI sform/qform](https://nifti.nimh.nih.gov/nifti-1/documentation/nifti1fields/nifti1fields_pages/qsform.html/document_view.html)；[FSL cluster 的连通簇说明](https://fsl.fmrib.ox.ac.uk/fsl/docs/statistics/cluster.html)。本软件独立实现阈值与连通簇过滤，不调用 FSL/SPM 的统计推断引擎。
