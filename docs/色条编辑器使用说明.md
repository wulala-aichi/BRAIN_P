# 色条编辑器（3.2 / 第二阶段）

更新后刷新 `dist/index.html`。全部功能在本地运行，不上传数据，不需要服务器。

## 主视图

左侧新增“色条编辑器”。在自定义伪彩或网络图层中使用；Allen 解剖色不是连续数值映射，不显示数值色条。

- **显示、方向、位置和对齐**：横/纵向独立于上/下/左/右位置；可在对应边缘起始端、居中、末端对齐。色条使用独立区域，不覆盖脑片。侧边或较长纵向色条会改变导出画布长宽比，不改变原始解剖轮廓或数值。
- **长度和厚度**：单位为导出毫米。空间不足时会受可用宽度限制；状态行显示实际长度。图版小面板可能需要缩小色条，并显示最终毫米和字号。
- **字号、最多刻度数、数字格式**：支持自动（4 位有效数字）、固定小数位和科学计数法。自动刻度在空间不足时减少数量，避免重叠；状态行和 SVG 元数据记录实际刻度。中文长标题最多显示两行，过长部分省略。
- **自定义刻度**：用逗号分隔，2–11 个有限数字，必须严格递增并位于当前色阶范围内，例如范围为 −3～3 时输入 `-3,0,3`。无效的新输入不会应用。换数据或改变范围导致旧刻度不适用时，会提示并临时自动避让；请更新或清空自定义刻度。这不会阻止反转、分级或隐藏色条。
- **标题与单位覆盖**：留空时跟随原数值标题/单位。覆盖只改变标签，不转换数据单位，也不改变原始指标身份。原始单位仍参与共用色条校验。
- **反转配色**：同时反转脑图与色条，原始数值、p/q/n 和过滤结果不变。
- **分级**：连续，或 2–12 级等宽数值区间。每档使用该区间中心的颜色；最高端点属于最后一档。是显示分级，不是数据分组或统计检验。

数值范围仍在原“分区赋值 / 伪彩”区域设置：自动/手动范围和以零为中心的对称色阶。NA 和 Filtered 保持独立于数值色带。p/q 阈值描述随主图导出。

主视图 2D 和 3D 使用同一个底色映射。3D 的光照会影响看起来的明暗，色条代表材质底色，不表示表面光照后的逐像素 RGB。

## 图版面板

进入右上角“图版编辑器”，加入更新版本捕获的定量切面、完整视图或 3D。选中面板，在“图版色条”的“编辑对象”选择“当前选中面板”。普通面板模式编辑首个选中面板；要统一修改多个面板，请使用共用色条。

每个面板保存捕获时的数值范围、指标、单位、过滤规则及配色。面板保留其固定数据范围；如果需要更换原始范围/色带，请在主视图修改后重新加入。

- 2D 面板通过原始数值属性重新着色，并同步更新标签明暗对比；不从颜色猜回数值。
- 新捕获的 3D 面板保留相机、半球、显示设置、实际数值/通过筛选的状态及实验场景配方。修改反转或分级会真正重渲染场景，保留原相机和几何；不会借用主视图后来改变的数据。重渲染期间界面会短暂锁定，完成后恢复。
- 原始 3D 像素可通过撤销恢复；保存项目后仍可继续重渲染。主视图的数值和相机不受图版编辑影响。
- 旧快照缺少可验证的映射或 3D 配方时，请从主视图重新加入；不会只换图例来冒充重新映射。
- 含定量影像位图的切面快照可编辑色条样式，但反转/分级被锁定，因为快照不包含逐体素原值。请在主视图修改后重新捕获。主视图真实精细标签位图已支持同步反转/分级，色条使用同一实际范围。

## 共用色条

1. Shift 点击，或全选至少两个定量面板。
2. 点击“选中面板共用色条”。软件会检查原始指标、量纲、数值类型、范围、色带/反转/分级、缺失颜色和过滤定义。
3. 校验通过后只显示一条共用色条，自动重排全部面板并预留空间。
4. “编辑对象”选择“共用色条”。改变反转/分级会同步所有成员，包括真正重渲染的 3D 面板。
5. 点击“关闭共用色条”恢复各面板自己的显示设置。

组名应写入**面板标题**，原数值标题应统一为实际指标。例如 Control 和 Treatment 的面板都使用 `Signal`、相同单位和固定范围，再分别设置面板标题为组名。不要仅改“标题覆盖”来合并不同指标。

如果单独改变其中一个成员的映射或单位标签，原共用色条不再显示，并按照各面板自身显示开关恢复独立色条，同时给出警告。不同单位即使覆盖成同一个标签，也不能绕过校验。

## 保存与导出

- 主视图设置、面板色条、共用色条以及 3D 配方均保存到完整项目。图版仍使用 IndexedDB 自动暂存；长期保存请导出完整项目文件。
- 旧项目没有色条配置时使用默认设置；不影响其原始赋值、坐标和统计数据。
- SVG 保留 2D 路径、色条和文字；3D 场景是内嵌位图，其图版标题/色条仍是矢量。主 3D 视图依然仅提供 PNG，不把渲染结果冒充矢量表面。
- PNG 支持原来的 150/300/600 dpi 和真实 DPI 元数据。透明背景与白底均覆盖新色条区域；编辑框、忙碌遮罩不会进入导出。

手动标注/局部放大、多条件矩阵及 PDF/TIFF 仍属于后续第三至第五阶段，见 `PUBLICATION_PLAN.md`。
