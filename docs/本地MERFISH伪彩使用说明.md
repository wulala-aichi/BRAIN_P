# 本地 MERFISH 伪彩叠加（3.9.0）

## 使用

1. 双击项目根目录的 `启动本地MERFISH.cmd`（或运行 `启动本地MERFISH.ps1`）。服务只监听本机 `http://127.0.0.1:8765`，不上传数据。
2. 刷新 `dist/index.html`，进入“研究工作台 → 本地 MERFISH”，点击“连接 / 检查本地数据”。
3. 勾选数据集，选择基因，点击“加载并叠加当前视图”。切换片层、网格或三视图会按指定片厚重新读取匹配细胞。默认 Slc17a7，可选择本地全部 1122 基因。
4. 在“着色内容”选择基因表达连续伪彩，或按 Class/Subclass/Neurotransmitter 分类色；可进一步筛选某个细胞类型。
5. 调整色带、共用/手动色阶、表达下限、不透明度和点大小。颜色/大小的改动重用已加载数值，不必重复读取矩阵。
6. 点击“显示 3D 点云”读取所选数据集的全体可显示 CCF 细胞，并按点数上限确定性抽样；背景可保留当前玻璃脑分区、仅脑壳或仅点云。

原离线 HTML 已验证可连接本机服务。若其他浏览器限制本地文件访问回环服务，可直接打开 `http://127.0.0.1:8765/`，再打开原完整项目。两种网址的浏览器本地草稿是分开的，完整项目文件可互相导入。

## 坐标与颜色含义

- 以超出 JavaScript 安全整数范围的 `cell_label` **字符串**精确连接 H5AD、细胞元数据和 `ccf_coordinates.csv`，不按浮点数读取细胞 ID。
- 只使用 CCF 文件中的 x/y/z：应用 AP=x、DV=y、ML=z−5.695 mm，与当前图谱的原生 NIfTI RAS x / 体积边缘坐标一致。切片元数据里的 x/y/z 不用于 CCF 叠加。这不是 bregma 换算或自动配准。
- 表达值直接取 `*-log2.h5ad` 的 X，不再次取对数。0 是有效表达值；非有限值排除并报告，不补 0。不把点颜色称为原始转录本计数。
- 全局自动色阶来自当前查询全部匹配细胞，跨同一网格的片层共用；手动色阶适合固定范围展示。色阶不改变数值。
- 2D 表示片厚内细胞中心投影；点大小是显示参数，不是细胞直径。3D 为细胞中心点云，不是组织分割、脑区密度或体积测量。
- 细胞数超过显示上限时，按原矩阵行顺序使用确定性间隔抽样，图例报告显示数/全部匹配数及 stride。显示图不用于未经校正的细胞计数统计。

坐标与字段解释依据 [Allen Zhuang MERFISH 官方教程](https://alleninstitute.github.io/abc_atlas_access/notebooks/zhuang_merfish_tutorial.html) 和 [Allen CCF 原生体积说明](https://alleninstitute.github.io/abc_atlas_access/notebooks/ccf_and_parcellation_annotation_tutorial.html)，具体覆盖以本机文件的 QC 为准。数据为 20230830 表达/CCF、20231215 元数据/分类和 Allen-CCF-2020/20230630。

## 保存与导出

- 主图可导出 SVG（2D）、PNG/PDF/TIFF；MERFISH 点层作为真实原生坐标栅格叠加，图例单独预留底部空间。3D 场景为位图。
- 可将当前视图加入图版。图版是快照，后续调整基因/色带不会修改已加入的旧快照。
- “导出当前叠加数据 / 来源 JSON”含所绘制细胞的 CCF 坐标、表达值、cluster_alias、dataset_index、obs_index，以及查询条件和源路径/缓存指纹。obs_index 是对应源 H5AD 的行号，可回溯其 cell_label，不是原始大整数 ID 的数值转换。
- 完整项目保存当前已加载的显示细胞和分类配色，可在没有服务时重现同一视图。换基因、片层或数据筛选仍需要本机服务。
- 浏览器轻量草稿只保存设置配方，不保存大点集；刷新后会从仍在运行的服务重新加载。服务未运行时明确提示，基础图谱仍可使用。

## 文件与运行环境

- 原始 H5AD/CSV 全程只读。缓存为 `tools/cache/merfish/`，本机实际约 566 MB；首次建立需等待，随后直接复用。
- 指纹由源路径、大小、修改时间和坐标契约生成，用于缓存版本匹配，不宣称为原文件内容 SHA256。
- Python 使用本机 Codex bundled Python，项目独立 `tools/merfish-python/` 中安装 h5py 3.16.0，numpy/pandas 来自 bundled runtime。没有改系统 Python。
- 服务进程是 `tools/merfish_server.py`，只提供固定的 MERFISH 查询接口与应用主页，不提供任意文件浏览。
- 如需不同目录/端口，可运行 `启动本地MERFISH.ps1 -Root '其他数据目录' -Port 8766`，并修改界面服务地址。
