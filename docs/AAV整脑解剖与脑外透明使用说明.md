# 整脑解剖与严格脑外裁切（3.13.2）

保存当前项目后刷新软件，打开“研究工作台 → Allen AAV 投射”。

“切面背景”选择 **整脑 Allen 灰度解剖（严格去除脑外信号）**。保留脑内所有灰度解剖，不以病毒阳性区域裁切。灰度背景和AAV投射共用同一Allen脑轮廓，严格隐藏脑模板之外的黑矩形、紫色散点及彩色杂质。内部标注空洞填充，不因脑室或未标注区把整脑灰度挖空。该设置为新建AAV图层的默认值。

“画布背景颜色”仍可选择透明、白色、黑色或自定义。想让脑外完全透明，请同时选择画布“透明”；白/黑画布会在透明脑外显示所选画布色。PDF阅读器通常以白色显示透明页面。

灰度模板源为官方10 µm NIfTI，显示采样50 µm；裁切轮廓沿用当前Allen图谱的100 µm轮廓。该处理仅用于结果展示，不是新的高分辨率脑组织分割。裁切在显示平滑之后应用，不让平滑颜色延伸到模板外；不按杂质大小进行脑内清理，也不删除脑内弱信号。

AAV原始体素、全量MIP数据、颜色、阈值、平滑参数和原始统计均不改变。图例中的Raw matches仍是源数据阈值匹配数，不是裁切后的可见像素数。原始数据文件不删除、不覆盖。仅信号模式、Allen分区背景和旧版采样投射同样严格隐藏模板外信号。

3.12及3.13已保存NIfTI背景的完整项目可离线获得严格裁切，PNG/SVG/PDF与新建图版快照使用相同裁切。已有图版快照不会自动替换，需重新加入当前视图。3.13.0明确保存的“仅信号”模式仍保留，请在下拉框切回整脑解剖。单片、网格及三正交视图共用此裁切。
