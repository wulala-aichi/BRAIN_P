# MRI 多体积 NIfTI 使用说明

统计展示现在可以直接载入 `.nii` / `.nii.gz` 多体积文件，无需先拆成单个 3D 文件。

1. 刷新软件页面，进入“MRI / NIfTI 统计展示”。
2. 解剖模板选择你有权使用的本地标准模板。
3. 统计结果直接选择已在同一空间中的本地4D NIfTI文件。
4. 文件下面会出现“选择子体积 / 4D 帧”菜单。
5. 按上游分析说明选择正确的子体积和统计类型。不要假定第2帧必然是Z图，也不要把均值差当作Z值。
6. 核对配准、空间缩放、阈值及簇条件后，点击“应用阈值”。

每次切换子体积，旧的统计叠加和簇表都会清空，须重新应用阈值。AFNI 类型从 BRICK_STATAUX 元数据识别，不根据名称猜测；没有统计类型元数据的文件仍需手动核对“统计图类型”。普通 4D 文件按 Volume 1、Volume 2 等列出，不假定其为统计结果或动态时间序列。

完整项目保留原始多体积文件和当前选择；重新打开可继续切换其他子体积。旧版单个 3D 项目仍兼容。SVG/图版元数据及簇表 CSV 记录所选子体积；CSV 的 `subvolume_index_0based` 使用从 0 开始的索引（界面第 2 项对应 1）。阈值掩膜只导出当前所选子体积的 3D 结果。

功能验证：原文件第 2 子体积在双尾未校正 voxel p≤0.001、k≥20、26 连通、原模板正值掩膜条件下，保留 10 个簇、699 个体素；与单独 3D 文件的既有结果一致。簇大小过滤不是 FWE/FDR 校正。空间缩放沿用明确选择，不自动把模板头坐标除以 10。
