# 位点、电极玻璃脑与球柱编辑（3.7.0）

刷新 `dist/index.html` 后使用，仍为离线单 HTML，不需要安装新依赖。

## 位点：空白输入，空心框线

- 图版编辑器 → 绘制工具 → 注射位点：默认只有空心圆框，不自动添加文字；点击放置后可改为空心方框、调整直径、颜色和线宽。旧项目明确选择的靶点/实心圆点/十字仍保留。
- 研究工作台 → 位点/电极玻璃脑：点击“新建空白对象”，输入 AP、ML、DV，再“添加 / 更新对象”。空白不当作 0，也不自动生成实验位置。
- 位点默认内部透明，直径仅为图示尺寸，不表示注射扩散范围。

## 电极：真实可旋转的玻璃脑

1. 研究工作台 → 位点/电极玻璃脑，选择“电极 / Neuropixels”或光纤。
2. 输入入口和尖端的 CCF mm 坐标，设置颜色、柄宽、柄数、间距和示意触点数。
3. 点击“添加 / 更新对象”，再点“显示玻璃脑（3D）”。拖动旋转，滚轮缩放；玻璃脑不透明度可调。
4. 从“已添加对象”选择后修改，或删除选中对象。坐标与参数随完整项目和浏览器本地草稿保存。

AP/DV 为体积前/背缘距离；ML 左负右正。这不是 bregma 坐标，不执行自动配准、手术规划或硬件通道定位。多柄围绕中心轨迹对称排列，触点为示意而非厂商 CAD。示例只有主动点击按钮才加载，且标记 SIMULATED。

## 球大小和柱粗细：全局与单个对象

- 3D 主界面左侧“功能连接球柱 · 大小编辑”：直接输入倍率或拖动滑块，范围 0.1–5 倍。
- 研究工作台 → 连接网络 → 直接编辑球大小 / 柱粗细：可选择按权重或固定柱粗细；固定模式以“最细柱半径”为基础。
- 选择一个可见球或柱，填写该对象的显示直径，点击“应用”。单独指定的直径优先于全局倍率；“恢复自动尺寸”后重新遵循映射与倍率。
- 所有尺寸只改显示，不修改权重、坐标、度或强度。尺寸、单独覆盖和实际显示半径随项目/节点导出保存。

## 导出

当前 3D 玻璃脑、电极和球柱可导出 PNG / PDF / TIFF，也可作为快照加入图版。3D 场景为位图；图版的空心位点标注是矢量。修改参数后，已加入的旧快照需重新加入。导出包含 CCF 空间、示意性质及实际显示尺寸说明。
