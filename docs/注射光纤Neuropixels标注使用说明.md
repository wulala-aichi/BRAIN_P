# 注射位点、光纤与 Neuropixels 图版标注

打开 `dist/index.html` → 右上角“图版编辑器” → 加入当前活动切面 → 左侧“手动标注与局部放大”。本版按用户要求先实现图版标注，不会在可旋转的三维脑模型中新增实体。

## 注射位点

1. “绘制工具”选择“注射位点”，在脑图上点击。
2. 可选择靶点、实心圆点或十字；调节颜色、直径、线宽和标签。
3. 拖动位点整体移动；橙色起点为位点中心，终点为引导标签位置。也可输入来源图宽/高百分比精确调整。

位点直径是图版显示参数，不代表注射体积、病毒扩散或组织损伤范围。

## 光纤

1. 选择“光纤”，从入口向尖端拖动。
2. 拖动入口/尖端手柄调整位置、长度和方向。柄宽按图版毫米设置。
3. 可开关光照锥，调节示意锥长、角度和不透明度。
4. 标签可隐藏，或通过 X/Y 偏移移到脑片外。

光照锥是图形示意，不是依据功率、波长或组织参数计算的光场。

## Neuropixels 多电极

1. 选择“Neuropixels 电极”，从入口向尖端拖动。
2. 设置 1–4 柄、柄宽、柄间距、每柄示意触点数及远端记录区段。
3. 调节颜色、标签与偏移；拖动两端调整方向和插入轨迹的显示位置。

柄、触点数和间距用于结果图示意，不绑定某个硬件型号，也不是实际通道坐标或制造商 CAD 几何。真实轨迹、通道和组织定位应依据实验配准数据另行核对。

## 局部放大、保存和导出

- 新建局部放大插图默认包含来源面板的手动标注与植入物。选中插图后可关闭“显示来源图的手动标注 / 植入物”。
- 放大直接使用同一来源几何及标注，不补造细节。放大后的示意符号随图像等比例放大。
- 所有参数随完整项目与浏览器图版草稿保存；复制/删除来源面板时同步复制/移除这些标注。
- 支持选中删除、撤销/重做；SVG/PNG 导出保留符号、标签和适用的放大比例尺，不包含编辑手柄。
- 所有宽度、符号直径、柄间距、锥长和标签偏移中的 mm 均为最终图版毫米，不是组织或硬件的真实毫米。入口/尖端位置依附来源快照坐标；本模块不是手术规划工具。
