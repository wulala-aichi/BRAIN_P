# 玻璃脑分区与独立参数区（3.8.0）

刷新 `dist/index.html`，点击“研究工作台 → 位点/电极玻璃脑”。

## 解剖分区

1. 点击“显示玻璃脑（3D）”。不需要先添加位点或电极。
2. 在“玻璃脑 · Allen 分区与透明度”中开关分区，输入百分比或拖动滑块。0% 全透明、100% 不透明。
3. “分区显示范围”可选全部或仅勾选的分区；通过缩写/英文全名查找并勾选关注的脑区。
4. “单个分区不透明度”可覆盖某个脑区的全局值；点击“恢复跟随全局”清除此覆盖。
5. 下方“玻璃脑不透明度”只调整外部脑壳，与分区、电极宽度和连接权重无关。

分区使用 Allen 解剖配色，独立于主界面的数值颜色与筛选。显示半球仍由主界面控制。当前网格覆盖 356/357 个聚合结构，c 在 100 μm 网格中缺失。透明表面重叠会加深颜色，建议论文图只显示关注的脑区。

## 参数与展示不叠加

- 研究工作台现在是非模态停靠参数区，不再覆盖脑图。
- 桌面端：参数在左、实时脑图在右，各自独立滚动；脑图可直接拖动旋转、滚轮缩放。
- 窄屏端：脑图在上、参数在下，互不遮挡。
- 点击“收起参数”回到原来的渲染设置侧栏。再次点击顶部“研究工作台”可重新打开。
- “显示玻璃脑”或“显示球柱图”不会关闭参数区，便于边调节边查看。

分区选择、全局与单区不透明度随完整项目保存，刷新/重新导入可恢复。PNG/PDF/TIFF 和新加入的图版快照使用实际分区渲染结果；已加入的旧快照不自动更新。
