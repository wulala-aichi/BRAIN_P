# 多条件比较矩阵

入口：打开 `dist/index.html` → 右上角“研究工作台” → “条件矩阵”。先在“数据/QC”导入动物级数值长表，也可使用已有点定量或影像脑区均值表。日常使用离线完成。

## 选择条件

1. 行、列分别选择组别、时间点、指标、片层中的两个不同维度。其他两个维度自动组成分页，例如“组别 × 时间点”按指标和片层分页。
2. 在组别、时间点和指标列表中多选；Ctrl/Command 点击可选多项。选择全部时，新追加的同类条件会自动纳入。空时间点显示“未指定”，作为精确独立类别处理，不等同“全部时间点”。
3. 选择半球及冠状/矢状/水平面。输入片层毫米位置，或使用主界面片层、指定范围均匀选片。坐标吸附到已有浏览片层，不插值，也不是 bregma 坐标。
4. 超过每页行/列数时自动分页；每页最多 8×8，单次最多 512 个条件单元。超出时分批选择。图版物理尺寸上限为宽 400 mm、高 500 mm；过大时会提示减小每页行列数或单元尺寸。

## 三种结果

- **组均值**：每个精确时间点、组别、指标、半球内，同一脑区每只动物等权贡献一个值。重复或跨来源重复记录不会静默求平均。
- **B−A 差值**：选择参考 A 组，其他已选组分别作为 B，与同一时间点的 A 比较。A 不重复作为 B 绘制。差值保留原指标单位；小样本仍可有描述性差值，但不能因此声称有有效统计检验。
- **Hedges g**：显示独立组的标准化效应量；单位为无量纲，不与原值/差值混用。

统计沿用已有独立组 Welch / Hedges g。BH 按指标、精确时间点、半球、B−A 对比中的有效脑区 p 值计算；展示多个片层不会重复检验或重新扩大 BH 集合。不新增配对、重复测量、协变量或纵向模型；同一动物跨时间点只分开展示，不做纵向推断。

## 色阶与缺失

- 同一指标、原单位和结果类型在所有已选条件、所有页共用范围。不同指标各有独立色条；同名指标单位不一致会拦截，不自动换算。
- 组均值默认 Viridis，范围覆盖所有已选条件的脑区均值；差值与效应量默认蓝白红、以零对称。
- 展开“分指标统一色阶与色条”，可逐指标固定上下限、切换色带、反转、分级、编辑刻度/数字格式/标题/单位及色带尺寸。矩阵内部固定为底部横向排列，避免与单元布局冲突。
- 更改条件、范围或配色后，点击“生成 / 更新矩阵”。旧预览会明确提示未更新，并拦截旧结果导出，防止标签和真实颜色不一致。
- 缺失条件显示 `No data`，不是数值 0；无法估计效应量显示 `No estimable value`。存在脑区数据但本切面没有赋值脑区时单独提示 `No assigned region in section`。
- 单元底部 N 是该条件中独立动物总数，ROI n 是各有值脑区样本量范围；逐脑区 n、统计状态及 p/q/CI 见导出 CSV。缺失单元也在 CSV/manifest 中记录，不被静默省略。

## 坐标和排版

每页各单元使用相同方向、切面位置及统一 viewBox/显示比例；调整预览缩放作用于整张矩阵，不改变图版毫米尺寸。脑图为正视；原主界面视图和数据赋值在生成后恢复。

矩阵展示的是**脑区汇总值在切面上的投影**，不是逐切片重新定量，也不是体素信号重建。同一脑区出现在多个片层时沿用同一条件的脑区统计值。矩阵不混入当前主图的实验点、轨迹、ROI 或原始图像背景；实际精细标签适配仍保留其位图属性。

“排版与显示”可调单元大小、间距、每页行列数、字体、标题和透明背景。密集矩阵建议关闭脑区名称，使用行列标题和后续局部放大突出关键区域。正视新切面可显示按原图校准的比例尺。

## 图版、保存和导出

- “当前页加入图版”或“全部页加入图版”生成固定矢量快照，保留内部的多指标色条、来源 SHA256、条件和范围。受图版 64 面板上限约束；可分批加入。全页矩阵不强行合并为一根全局色条，改变映射应回到条件矩阵重新生成。
- 图版里仍可移动、缩放、添加文字/箭头/植入物示意及局部放大。完整矩阵页缩得过小会导致内部文字变小；优先独立导出各页或增大图版，不建议将大量完整矩阵挤进小面板。
- 当前页可导出 SVG、PNG、PDF 或 TIFF；位图支持 150/300/600 dpi，包含真实 DPI 元数据，可选透明或白底。二维 PDF 路径/普通文字保留矢量，描边文字、影像/精细标签仍是嵌入位图；中文字体内嵌。详见 `PDF_TIFF导出使用说明.md`。
- “全部页多页 PDF”将所有条件页写入一个文件，保留各页真实尺寸。
- “全部页 + 数据 ZIP”可选择 SVG/PNG/PDF/TIFF，包含全部图页、`manifest.json`、原始动物长表、逐单元脑区值 CSV、完整项目和方法说明。
- 完整项目保存条件、映射与来源配方及已加入图版的固定快照。重新打开项目后，工作台恢复配方，点击“生成”重新渲染预览；已加入图版的矩阵快照直接恢复，不随新预览变化。
- 生成/打包时可取消；不会导出未完成的部分结果。生成失败或取消时保留上次完整结果，并恢复主图设置。

模拟数据仅用于测试，不可作为实验结果。
