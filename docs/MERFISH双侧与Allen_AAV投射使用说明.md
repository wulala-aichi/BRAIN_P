# MERFISH 双侧展示与 Allen AAV 投射（3.11.0）

两个模块都在“研究工作台”，可以叠加使用。先双击 `启动本地MERFISH.cmd`，再刷新软件。服务仅监听本机，不上传数据；也可打开 http://127.0.0.1:8765/ 。离线文件和本机地址的浏览器轻量草稿分开，有未保存内容应先保存完整项目再切换网址。

## 1. MERFISH 双侧对称

进入“本地 MERFISH”，连接后在“半球展示”选择：

- 原始数据：保持实测覆盖，不镜像；旧项目默认此模式。
- 左侧源数据 → 双侧对称：仅取左半球真实细胞，在 ML=0 处反射至右侧。
- 右侧源数据 → 双侧对称：仅取右半球真实细胞，反射至左侧；源侧没有数据时不会凭空补出细胞。

再点击“加载并叠加当前视图”或“显示 3D”。支持三切面、网格、三视图、3D 点云与分区热图。右侧矢状面会读取对应左侧源片层再反射，不是把空的右侧源查询当成镜像。

镜像仅是展示副本，不代表测得了对侧细胞。AP、DV、表达值、细胞类型和源 H5AD 行号保持原值，只改变 ML 符号。完整数据包含 `is_mirrored` 和 `source_ml`，原始文件不变。

所有统计仍使用源半球真实细胞，分区统计 CSV 仅导出源侧记录。显示上限约束真实源采样，双侧绘制点最多为其两倍；界面分别报告源细胞与副本。图中保留镜像说明，即使关闭普通图例也不会隐藏该说明。多个片层的片厚重叠时，同一源细胞可能出现在多个片层，不能把逐片计数相加当作独立细胞。

## 2. Allen AAV 投射

进入“Allen AAV 投射” → “检查本机 AAV 数据”。可按脑区缩写、实验 ID 或本地已知品系查找。默认示例为 VTA 实验 `160539283`，本地 metadata 标注 Slc6a3-Cre。

服务从用户显式指定的只读目录发现可用实验（相同实验合并分辨率，不合并信号）。例如：

- `--aav-root <第一套本地grid_volumes目录>`
- `--aav-root <第二套本地grid_volumes目录>`

主目录大多数实验有 50 µm 的 `projection_density` 与 `data_mask`，部分其他本地实验有 25 / 100 µm；下拉框只列出实际存在的配对文件。实验目录存在但缺少有效掩膜时不视为可用投射。需要别的目录时可运行 Python 服务并使用可重复的 `--aav-root` 参数，不会扫描整个磁盘。

参数：

- 投射密度阈值：原始 `[0,1]` 比例；只绘制大于 0 且达到阈值的有效体素。
- 片厚：2D 使用片厚内已显示体素的最大密度投影（MIP），不是平均密度或全脑投影。
- Linear / Log display：仅调节颜色映射。对数显示增强弱信号，不修改保存的投射密度；色条刻度仍为原始比例。
- 自动 / 手动色阶、不透明度、色带和 3D 点显示尺寸可以独立调节；尺寸不是轴突直径。
- 显示上限采用确定性体素抽样，图例报告显示 / 匹配数量。达到上限可能漏掉细小结构，不能据抽样图定量。
- 排除注射区：只在有同分辨率 `injection_fraction` 时可执行，排除其大于 0 的体素。文件缺失时明确报错，不会把“未排除”冒充“已排除”。主目录多数没有该文件。

3D 为真实注册体素中心，不是单根轴突、纤维流线或推断出的功能连接。AAV 不跟随 MERFISH 的镜像设置，也不跨实验平均。若同时打开 MERFISH 分区热图，AAV 的背景选项不会隐藏该热图。

## 3. 坐标、掩膜和来源

按 Allen CCF 网格 AP、DV、左右轴解释 NRRD，首轴最快；在原点 0 的支持网格中 AP=i×分辨率、DV=j×分辨率、ML=k×分辨率−5.695 mm。三个切面的坐标与现有脑图及 MERFISH 一致，不做 bregma 换算或自动配准。非预期全脑尺寸、方向或原点会拒绝加载，不猜测空间变换。

仅绘制有限且 `data_mask >= 0.5` 的体素；非有限 / 范围外密度不补零。完整项目与 JSON 记录实验 ID、分辨率、源路径/大小/修改时间、NRRD 头、查询、掩膜质控、采样和缓存来源指纹；指纹不是原文件全文哈希。

定义依据：Allen 官方 [Connectivity Grid Data](https://allensdk.readthedocs.io/en/1699-grid-data-docs/connectivity_grid_data.html) 说明投射密度为检测像素占体素像素比例、包含注射区；[Reference Space](https://alleninstitute.github.io/AllenSDK/_static/examples/nb/reference_space.html) 给出 AP / DV / 左右轴向。本软件的具体可用覆盖以本机文件检查结果为准。

## 4. 出图与保存

当前视图可导出 PNG / SVG / PDF / TIFF 或加入图版。2D 投射层为内嵌栅格，图例与解剖边界保留矢量；3D 为场景位图。与 MERFISH 同时使用时，两套图例和来源分别保留。

“保存完整项目”包含当前显示的实际体素 / 细胞，可离线重现同一图；轻量浏览器草稿只保存配方。更换实验、基因、片层、片厚或阈值需要本机服务重新读取数据。显示样式的改动重用已有数据。

## 验证入口

`qa/merfish_symmetry_backend_test.py` 核对真实细胞镜像、右侧矢状面、原始统计不加倍；`qa/aav_backend_test.py` 核对本机源体素、轴向、三个切面、左右分割和注射区排除；`qa/aav.test.mjs` 验证来源配方、连续色阶、完整/轻量保存及旧项目默认行为。
