# Mouse Atlas Studio · 新版界面上手指南（3.20）

打开 `dist/index.html`；如果页面已经打开，刷新即可加载新版。

## 先选任务

左上角“使用指南”提供四个入口：图谱浏览、脑区赋值、MRI 统计叠加、实验数据。指南只打开相关设置，不会自动导入示例、替换当前数据或修改统计参数。

图谱工作区的设置按四步排列：

1. **切片**：选择方向、半球、单片/网格/三视图/3D。网格中的“图间距与实际取片间隔”可以展开；版面图间距与实际取片坐标是不同参数。“2D 立体薄片”是可选的示意效果。
2. **数据**：在 Allen 脑区层级筛选脑区；展开“分区赋值 / 伪彩”导入 CSV，核对半球、数值类型与单位，再显示伪彩。也可以打开研究工作台叠加实验数据。
3. **样式**：设置着色、边线、透明度，展开色条编辑器调整标题、单位、尺寸与刻度。
4. **导出**：设置标注、背景、毫米图宽与 DPI，导出 SVG / PNG / PDF / TIFF；“项目与来源”用于记录数据与方法。

搜索框检索所有图谱设置，不限于当前步骤。例如输入“标签”“阈值”“色条”“DPI”或控件英文 ID。相关设置组会自动展开；清空或按 Esc 返回之前的步骤和展开状态。有些参数仅在对应视图/数据类型下启用。

四步标签可用左右方向键切换，Home / End 到达首末步骤；Tab 可逐项访问控件。

## 顶部的独立工作区

| 入口 | 用途 |
| --- | --- |
| 研究数据 | 动物表、点位、连接网络、注射/光纤/电极、ROI、MERFISH / AAV 等 |
| MRI / 统计 | 导入 NIfTI 模板与统计图，核对空间，设置统计值、p/q 与簇条件，导出二维统计图 |
| MRI 3D / 高级 | 多图层、3D 体渲染、相机与裁切、ROI 和多种组合出图 |
| 图版排版 | 组合固定结果快照、编辑标注与布局、导出整版 |

MRI 窗口左侧提供分组跳转按钮，可直接定位到数据、阈值、视图或导出设置。高级 MRI 需要交互旋转/绘制时切到“交互调整”，出图时切回“成图预览”。

## 保存与恢复

右上“打开项目”兼容原来的项目和旧设置；“保存项目”下载完整项目 JSON。图片导出不等于项目保存。回转箭头恢复默认前会要求确认；取消不会清空数据。已导出的项目文件不受影响。

引导卡可以收起，并记住当前浏览器的选择；“使用指南”始终可重新打开。收起引导不影响图谱或导出。

## 必须保留的专业边界

- 图谱使用 Allen CCF 体积坐标，MRI 使用 NIfTI 文件头世界坐标；两者都不自动转换为 bregma。
- MRI 叠加前须确认已经配准；显示层不执行自动配准。显示阈值或簇大小过滤不等于完成 FWE/FDR 校正。
- 平滑、配色、布局和隐藏文字是显示操作，不会重新计算输入数据的统计分析。
- 核心图谱和本地 NIfTI 功能可离线使用；MERFISH / AAV 大型数据可能需要先启动对应本地服务。
