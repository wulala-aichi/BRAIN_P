# 图版编辑器

打开 `dist/index.html`，点击右上角“图版编辑器”。可混排面板、编辑独立/共用色条及同步映射，加入文字、脑区引导标签、箭头、框选和局部放大；也可从研究工作台“条件矩阵”加入当前页或全部页，保留内部独立量纲色条及条件/来源。支持 SVG/PNG/PDF/TIFF 导出；详见各功能使用说明及 `PDF_TIFF导出使用说明.md`。

## 加入面板

1. 在主界面设置方向、坐标、半球、配色、标签和显示模式。
2. 打开图版编辑器，选择：
   - **当前活动切面**：网格中当前选中的一片，或三视图中当前方向的一片；保留切面坐标、脑区标签和适用的 1 mm 比例尺，不带整图总标题。倾斜薄片不显示普通比例尺。
   - **完整当前视图 / 3D**：完整单片/网格/三视图，或当前相机角度的三维高分辨率 PNG。
   - **动物统计图**：研究工作台“组间比较”中已生成的当前脑区独立动物散点图。先在工作台计算比较，再加入。
3. 点击“返回图谱”切换片层/条件，再加入其他面板。新面板加入时自动将全部面板重新网格排版；建议先加入所有内容，再做最终的手工微调。

面板是**固定结果快照**，不会随主视图更改。需要更新数据时，删除旧面板并重新加入。2D 的原始路径和文字仍是矢量，3D 和影像叠加保持位图；不能通过图版编辑恢复位图中不存在的细节。每个面板记录捕获时间、图谱指纹、坐标/相机、原始色阶和项目来源等信息。

## 编辑与排版

- 画布、页边距、面板位置与尺寸均以毫米为单位。图版尺寸独立于主视图的导出宽度。
- 点击面板选择；Shift 点击多选；也可通过左侧面板列表选择或全选。
- 拖动面板移动，拖动右下角色块调整尺寸；“拖动吸附”使用 1 mm 网格。
- 精确修改 X/Y/宽/高；图形内容始终等比例显示，不拉伸解剖结构。
- 总标题、面板标题、编号分别编辑。面板标题为最多两行，超长文字省略显示；缩短标题或增大面板可显示更多内容。标题与图形有独立空间。
- 可输入网格行标题与列标题，每行一个。更改行列标题时会重排全部面板，并在画布顶部/左侧预留独立空间；之后手工移动面板时应检查对应关系。
- “网格排版”在选中两个以上面板时只处理选中项，否则处理全部。对齐、等宽/高与均匀分布作用于当前选中面板。
- 面板可复制、删除、上移/下移一层；支持撤销/重做。画布中的细虚线、选中框和缩放色块仅为编辑辅助，不进入导出。
- 重叠时下方显示警告。可以通过网格排版恢复无重叠布局；允许保留用户有意的重叠布局。
- 画布过小时会保留标题所需的最低空间；网格装不下所有面板时会提示增加画布高度或列数，而不会压缩标题到图像上。

## 保存与导出

- 图版自动暂存到当前浏览器的 IndexedDB（大容量存储），刷新后恢复；不要把浏览器暂存当作长期备份。更换浏览器、移动 HTML 文件或清理站点数据可能无法读取原暂存。
- “保存完整项目”保存全部原始项目数据以及图版快照与布局。主界面上方“保存项目”按钮同样包含图版。
- 打开已有完整项目会恢复其中的图版；旧版无图版项目会得到空白图版，避免混入其他项目的面板。
- SVG 保留二维路径与文本，三维/影像为内嵌位图。PNG 支持 150/300/600 dpi，并写入真实 DPI 信息。棋盘背景和编辑框均不会导出。
- PDF 保留二维路径与普通文字；带描边文字/光晕、阴影和 3D/影像按所选 DPI 嵌入局部位图。TIFF 写入真实 DPI，透明为 RGBA，不透明为 RGB；字体与导出边界见 `PDF_TIFF导出使用说明.md`。
- 图版字体设置作用于矢量文字；三维 PNG 内已经烘焙的文字无法更换字体。
- “恢复默认设置”也会清空当前图版暂存；磁盘上已保存的完整项目不受影响。

完整升级顺序和阶段验收见 `PUBLICATION_PLAN.md`。
