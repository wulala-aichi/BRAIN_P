# 功能连接球柱图（3.6.0）

刷新 `dist/index.html` → 研究工作台 → 连接网络 → 顶部“功能连接球柱图 · 3D”。

## 快速开始

1. 点击“载入模拟功能连接示例”，再点击“显示球柱图（3D）”。内置示例是 10 个左右侧节点、45 条模拟无向连接，不是实测数据。
2. 调整最小绝对值、正/负筛选、最强边上限、球半径、柱半径、透明度和标签。常规功能相关图保留默认“无向”。
3. 鼠标拖动旋转，滚轮缩放；点击节点可查看度/绝对强度并把共享 CCF 坐标定位到节点中心，点击柱可查看权重。
4. 主界面的 PNG/PDF/TIFF 按钮可导出；图版编辑器用“完整当前视图 / 3D”捕获固定快照，之后可排版、标注与导出。

## 导入自己的数据

导入面板独立于旧版连接模块和其他研究数据。连接文件替换当前球柱图连接，不覆盖原有动物长表、点、轨迹、ROI 或上方旧网络。更改导入选项只用于下次导入，不重解释已加载连接。

### Allen 节点矩阵

选择相关系数 r、Fisher z 或一般权重，然后选择方阵格式。首行、首列为同序节点；支持 Allen 缩写、结构 ID 或英文名。用 `MOp|L`、`MOp|R` 明确左右侧。无后缀脑区按导入时的半球选项解析。

```csv
,MOp|L,MOp|R,CA1|L
MOp|L,1,0.72,-0.35
MOp|R,0.72,1,0.25
CA1|L,-0.35,0.25,1
```

无向矩阵必须对称，行列必须对应；对角线不绘制，不把缺失值当作 0。相关系数要求 [-1,1]，Fisher z/一般权重允许其他有限数值。软件只展示输入连接，不从时间序列估计相关，也不在此计算检验或 FDR。

未指定半球而使用 B 时，节点是双侧标签体积的汇总质心，可能靠近中线；不会凭空复制为左右两个节点。内置坐标来自 100 μm 显示标签体积质心，并不保证位于不规则脑区的内部。

### 边表

```csv
source,target,weight,p,q
MOp|L,MOp|R,0.72,0.01,0.03
MOp|L,CA1|L,-0.35,0.04,0.08
```

`p/q` 可省略。无向图一致的反向重复边会去重；权重或统计值不一致的重复会拒绝，不自行平均。需要合并不同动物、时间点或条件时，请在外部先完成明确的统计汇总，每次导入一套用于展示的连接。

### 自定义节点坐标

先导入节点表，再导入以这些 id 为端点的连接边表/矩阵：

```csv
id,label,region,hemisphere,ap,ml,dv,value,colour
ROI_A,Motor L,MOp,L,4.3,-2.1,2.4,2,#1f9d5a
ROI_B,Motor R,MOp,R,4.3,2.1,2.4,-2,#1f9d5a
```

必需列为 `id,ap,ml,dv`；`label,region,hemisphere,value,colour` 可选。坐标必须已经配准到 Allen CCF，单位 mm：AP/DV 距体积前/背缘，ML 是 NIfTI 左右坐标；不是 bregma。不会自动配准。半球与 ML 符号冲突时拒绝；体积外坐标在摘要中提示。节点表按 id 更新坐标库，现有同 id 节点同步更新；未被连接数据引用的坐标不会凭空出现在网络里。

可用 `value` 给球体伪彩（蓝白红、以 0 为中心）；缺失 value 为灰色，不补零。`colour` 为 #RRGGBB，用于“Allen / 节点表 colour”模式。

## 显示含义

- 球大小可固定，或使球体积随当前可见图的度/绝对强度线性变化；柱截面积随 |weight| 线性变化。最小/最大半径是显示参数，不是脑区真实半径。
- 先按绝对值、符号、可选导入 p/q 筛选，再取最强 N 条，最多显示 3000 条；不删除原始连接。有 p/q 筛选时缺失对应统计值的连接排除并计数。
- 度和绝对强度只描述当前可见网络。无向边对两个端点各贡献一次；有向模式度为入度+出度，绝对强度为入边+出边 |weight| 总和，不等同于完整原始网络指标。
- “保留孤立节点”控制筛选后无边的节点。主界面 L/R 半球筛选同样生效，跨侧连接在仅显示单侧时不显示。
- 透明脑壳、当前脑区表面、纯网络三种背景可选。“正常深度”会产生真实遮挡；“网络置顶”是示意叠加，不可用于判断前后位置。
- 有向箭头仅依据用户明确的有向输入；普通相关不能解释为因果。连接柱不是纤维追踪轨迹。

## 保存与导出

完整项目保存连接、节点、自定义坐标库、显示参数、原始 CSV 和 SHA256。浏览器轻量保存也保留这些数据，超容量时请使用完整项目；旧项目无该功能时保持关闭。

PNG/PDF/TIFF 包含球柱图及图例。3D 场景仍为嵌入位图，PDF 外部标题/图例保留普通矢量文字；不能恢复影像中不存在的分辨率。图版快照保存相机、节点、连接、参数及来源，后续主图改变不会更新旧快照，需重新捕获。

“导出可见连接/节点”会记录筛选后的边、坐标、度、绝对强度和显示半径；原始完整连接仍在项目中。导出分辨率和透明度见 `PDF_TIFF导出使用说明.md`。

本地 `examples/functional_connectome_*_simulated.csv` 以及模板按钮中的数据均明确为模拟数据，只用于测试。
