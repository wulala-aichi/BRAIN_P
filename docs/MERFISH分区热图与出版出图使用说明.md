# MERFISH 解剖分区热图与出版出图（3.10.0）

## 快速使用

1. 运行 `启动本地MERFISH.cmd`。刷新 `dist/index.html`，进入“研究工作台 → 本地 MERFISH”，连接本地数据。
2. 在“显示方式”选择“解剖分区热力图”。原有“细胞点图”保留；“分区热图 + 中性位置点”以中性色点标位置，色条只编码分区统计值，不把两种不同量混成一条色阶。
3. 选择基因或细胞类型、统计指标、片厚和最低细胞数，加载当前视图。冠状/矢状/水平、三视图及网格按各片层独立统计，共用数值色阶；3D 按所选全脑注册细胞汇总到分区表面。
4. 可以修改色带、手动色阶、不透明度和缺失色。“分区统计表 / 映射质控”显示前100行；“导出完整分区统计 CSV”包含所有行、分子分母与状态。
5. 左侧“画布与导出”选择单栏89mm或双栏183mm，点击“应用标准出版风格”，再导出 SVG、PDF、PNG 或 TIFF。可随后勾选透明背景、显示必要的区域名称或调整线宽。

## 指标与分母

| 内容 | 指标 | 计算 |
|---|---|---|
| 基因 | 平均表达 | 所选细胞中有限的源 log2 归一化值的算术平均，包括0；不是原始转录本数，也不是先求原始均值再log2 |
| 基因 | 阳性细胞比例 | 严格大于“阳性阈值”的细胞数 / 有限表达细胞数 ×100% |
| 细胞类型 | 计数 | 满足当前类型筛选的注册细胞数 |
| 细胞类型 | 比例 | 当前类型细胞数 / 同分区、同半球、同空间和置信度筛选下全部注册细胞数 ×100%；必须选择具体类型 |

所有统计均在点图抽样之前使用全部合格细胞。点图的表达下限和最多显示数不改变热图结果。基因模式中的类型筛选限制平均/阳性统计总体；类型比例的分母不随所选类型缩小。

`n` 为指标使用的统计分母；`eligible_cells` 保留区域全部合格注册细胞数。没有覆盖的区域和低于最小n的区域为缺失，不补0；有合格分母但目标类型计数为0时，0是有效结果。阳性比例和类型比例默认色阶0–100%，其他指标按全体可显示分区的共同范围着色，可手动固定。

合并多个数据集时，均值为细胞加权的描述性汇总，不是动物均值，不提供组间显著性。相邻片厚或三方向切面可包含同一细胞，因此表中逐片细胞数不能直接相加当作唯一细胞总数。

## 解剖映射与覆盖

原始细胞 `parcellation_index` 通过本地官方 Allen-CCF-2020 acronym 表、官方结构树，映射到最近的当前显示祖先，不按点图或平滑网格反推归区。688个源标签中686个可映射；0与987不强行分配。每个查询保存映射指纹、未映射数和分区样本量。当前二维几何仍是357个聚合结构，3D为100μm显示近似；细胞所属的源标签不因显示平滑改变。

二维热图描述该片厚中采到的细胞，不证明整个区域组织被完整采样。3D汇总同样取决于源数据的实际覆盖，不镜像补齐另一半球，不是组织密度或体积测量。

## 出版预设与导出

- Arial / Helvetica 字体；主标签和色条7pt；正文来源简注6.5pt；黑/深灰文字，白底、正视，无边框和装饰阴影，保留真实1mm比例尺。预设将MERFISH不透明度设为100%，避免透明混色改变定量色阶外观。
- 位图默认600dpi。二维纯分区热图的SVG/PDF保留矢量轮廓、文字和连续色条；点层、影像和3D仍为位图，不会变成矢量或提高原始定位分辨率。
- “出版预检”按最终主图宽度计算正文最小字号；排版太密导致小于6pt时，减少列数或增大宽度。图版再次缩小面板会同时缩小来源图中文字，请检查最终版面。
- 图面只保留必要标题、CCF坐标、比例尺、数值色条、缺失说明和片厚/n信息。完整来源、映射和方法仍在导出metadata、统计CSV及完整项目中。
- 可将“当前活动切面”或“完整当前视图 / 3D”加入图版，保留热图与独立图例。图版是固定快照，换基因后需重新加入。
- 完整项目保留所有已加载的分区结果与配方；无需重新读取H5AD即可重现同一视图。修改数据筛选或换片仍需服务。

这是通用出版预设，不代表满足所有期刊的专属图稿要求。3D光照会影响表面明暗，数值以统计表和色条的材质底色为准。

实际Slc17a7示例位于 `outputs/merfish_regions_v310_20261017/`，包含矢量SVG/PDF、600dpi PNG、3D PNG、分区CSV、来源JSON及可打开的完整项目。
