# AAV 官方 NIfTI 背景与显示平滑（3.12.0）

先运行 `启动本地MERFISH.cmd`，刷新软件，进入“研究工作台 → Allen AAV 投射”。

在“2D 解剖背景与显示平滑”中：

1. “切面背景”选 **Allen 官方 NIfTI 灰度模板**，然后加载当前切面。单片、任意行列网格和三视图都使用对应位置的模板灰度切面，不再以 Allen 彩色脑区填色作为底图。也可切回原有分区配色或无解剖填色。
2. “2D 投射平滑 σ”范围 0–0.30 mm。0 为原始体素像素；可从 0.03–0.08 mm 试起。平滑越大，小结构越容易变淡/合并，应随图报告参数。
3. “背景平滑 σ”独立控制模板（0–0.15 mm），不影响投射信号。Gamma 越大，中低强度背景越亮；背景不透明度控制其与页面的混合。

新建 AAV 图层默认选择官方 NIfTI 背景。旧完整项目仍保持旧的分区/采样渲染，以便离线原样重现；选择新背景或调整平滑后即使用新全量 MIP 渲染。

## 平滑的含义

新 2D 渲染按片厚内**全部有效源体素**生成标量最大密度投影（MIP），不受 3D 点数上限的抽样影响。之后对标量 MIP 做掩膜归一化 Gaussian 显示平滑，再应用显示阈值和伪彩；不是模糊已着色的 RGB 图片。无效覆盖之外不扩散，不把缺失补成零测量。

调平滑、Gamma、不透明度不会重新读取源数据，也不改变保存的原始投射密度、未平滑阈值匹配数量、注射区排除或统计。平滑后显示的色值是显示处理结果，不应用它重新计数或声称达到更高空间分辨率。3D 点云不受此 2D 平滑影响。
