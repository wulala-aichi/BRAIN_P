# Contributing

UseNode22 or24. Run `node scripts/test.mjs` and `node build.mjs`. Keep clinical/private study data out of the repository. Prefer deterministic synthetic fixtures, small changes and source-data provenance. Never turnmissing values intozero without explicit semantics. Do not imply registration, FDR correction or anatomical precision that the code does not provide.

Bug reports should include version, OS/browser, minimal reproduction, expected vs observed result, console error and a synthetic fixture when possible. Avoid uploading personal data or credential-bearing logs. Code contributions are accepted under the project MIT license; retain third-partydata/license distinctions.
